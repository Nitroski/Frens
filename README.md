# Friends? 👉👈

Run locally:

    npm install
    npm run dev

Deploy on GitHub Pages:
1. Push this folder to a GitHub repo (branch `main`).
2. Repo → Settings → Pages → Source: GitHub Actions.
3. Every push to `main` auto-deploys.

Using it:
- Open the site normally → Edit button (top right) lets you set the text and gif links.
- Hit Copy share link and send that link. People who open it see the page without the editor.
- Gif links must be direct image links (ending in .gif / .webp / .png). You can also drop a file in `public/` and use `./yourfile.gif`.
